## 1. ゲーム概要

| 項目 | 内容 |
|------|------|
| **タイトル** | Balling |
| **ジャンル** | 2.5D パズルゲーム（見下ろし型・オブジェクトは 3D） |
| **ターゲット** | PC (Windows) |
| **アートスタイル** | 神秘的・幻想的（青×金を基調とした深海×古代×宇宙の世界観） |
| **参考** | 崩壊スターレイル ver3.0〜3.7 オンパロス |

### コンセプト

プレイヤーは「巻き戻しの力」でパズルを回転させ、内部のボールをパズルの外に出すことを目指す。  
操作はシンプルながら、砂時計ゲージの管理と回転タイミングの読みが鍵となるパズルゲーム。

## 2. ゲームフロー

```
起動
 └─ メインメニュー
      └─ New Game
           └─ Stage 1（解放済み）
                └─ クリア → Stage 2 解放
                     └─ クリア → Stage 3 解放
                          └─ ...
                               └─ Stage 5 クリア → エンディング（TBD）
```

- ゲームを起動すると **Stage 1 が解放された状態** で始まる
- ステージをクリアすると **次のステージが解放** される
- 全 5 ステージを順番にクリアしていく
- クリア状況はセーブデータに記録され、次回起動時も保持される

## 3. クリア・失敗条件

| 条件 | 内容 |
|------|------|
| **クリア** | ボールがパズルの外枠から出た瞬間 |
| **失敗** | なし（詰まったら R キーでリセット） |

## 4. コアメカニクス

### 4-1. 操作

| 操作 | キー | 挙動 |
|------|------|------|
| 巻き戻しの力（発動） | `A` 長押し | パズルが **反時計回り** に回転・砂時計ゲージ消費 |
| 巻き戻しの力（解除） | `A` を離す | パズルが **時計回り** に回転・砂時計ゲージ回復 |
| ゲージ枯渇時に長押し | `A` 長押し | パズルは回転しない（無効） |
| リセット | `R` | ステージの初期状態に戻す（フェードアニメーション付き） |

### 4-2. 砂時計ゲージ

- `A` キーを押したときのみ画面に表示される
- **容量**: パズル **1 回転分** に相当
- `A` 長押し中: ゲージが減少する
- `A` を離している間: ゲージが回復する
- ゲージが満タン（1.0）に戻ると砂時計 UI が **非表示** になる
- ゲージ = 0 のときは反時計回りの回転が無効

### 4-3. ボールの挙動

- プレイヤーが直接操作することはできない
- パズルの回転に連動して **重力で転がる**
- 物理演算（Chaos Physics）で挙動を実現

### 4-4. パズル（外枠）

- ステージごとに外枠の形状（多角形）が異なる
- 内部に **仕切り線（壁）** があり、ボールは通過できない

### 4-5. 仕切り線の種類

| 種別 | 挙動 | エディタ識別色 |
|------|------|--------------|
| **固定** | 動かない | 青 `#4A7FC1` |
| **回転** | その場で回転する | 橙 `#E8A838` |
| **移動** | 軌道上を往復移動する | 緑 `#4CAF82` |

## 5. ステージ設計

### Stage 1 — 正六角形（チュートリアル）

| 項目 | 内容 |
|------|------|
| **難易度** | ★☆☆☆☆ |
| **外枠形状** | 正六角形 |
| **仕切り線** | 固定 × 1（水平、六角形の中段） |
| **ボール初期位置** | 六角形の下半分 |
| **ゴール出口** | 上頂点 1 か所 |

**攻略のポイント**  
パズルを反時計回りに回転させ、水平仕切りを乗り越えてボールを上部へ誘導する。  
操作に慣れるためのチュートリアルステージ。

---

### Stage 2 — 正方形（基礎）

| 項目 | 内容 |
|------|------|
| **難易度** | ★★☆☆☆ |
| **外枠形状** | 正方形 |
| **仕切り線** | 固定 × 2（L 字型を形成） |
| **ボール初期位置** | 正方形の左下 |
| **ゴール出口** | 右辺の中央 1 か所 |

**攻略のポイント**  
L 字型の仕切りが迷路を構成。回転方向と離すタイミングを組み合わせてボールを L 字の外側へ誘導する。

---

### Stage 3 — 正五角形（中級）

| 項目 | 内容 |
|------|------|
| **難易度** | ★★★☆☆ |
| **外枠形状** | 正五角形 |
| **仕切り線** | 固定 × 2（五角形の中段）、回転 × 1（中段固定仕切りの中心をピンとして回転） |
| **ボール初期位置** | 五角形の下部 |
| **ゴール出口** | 上頂点 1 か所 |

**回転仕切りの動き**  
パズル全体の回転に連動して中心ピンを軸に回転する。

**攻略のポイント**  
回転仕切りの向きがボールの通路を開閉する。砂時計ゲージの消費タイミングを計り、仕切りが「開いた」瞬間にボールを通す。

---

### Stage 4 — 正六角形（上級）

| 項目 | 内容 |
|------|------|
| **難易度** | ★★★★☆ |
| **外枠形状** | 正六角形（Stage 1 と同形・異構成） |
| **仕切り線** | 固定 × 2（上段・下段に水平配置）、移動 × 1（左辺に沿って上下に往復移動） |
| **ボール初期位置** | 六角形の右下 |
| **ゴール出口** | 左辺・右辺の中央付近に各 1 か所（計 2 か所） |

**移動仕切りの動き**  
左辺に沿って一定速度で上下に往復する。

**攻略のポイント**  
2 か所の出口のどちらを使うかを判断し、移動仕切りの位置を見てタイミングを合わせる。  
Stage 1 と同じ外枠でも内部が大きく異なることを体感させる。

---

### Stage 5 — 正八角形（最終）

| 項目 | 内容 |
|------|------|
| **難易度** | ★★★★★ |
| **外枠形状** | 正八角形 |
| **仕切り線** | 固定 × 3（水平 2 本 + 斜め 1 本）、回転 × 1（水平仕切りの交点をピンとして回転）、移動 × 1（下段区画内を左右に往復） |
| **ボール初期位置** | 八角形の下部区画 |
| **ゴール出口** | 上頂点 1 か所 |

**攻略のポイント**  
最も複雑な構成。回転仕切りが区画の鍵となり、移動仕切りが経路を塞ぐ。  
砂時計ゲージの管理・回転タイミング・移動仕切りの位相をすべて考慮する必要がある。

## 6. UI 仕様

### メインメニュー

| 要素 | 内容 |
|------|------|
| **New Game ボタン** | Stage 1 へ遷移 |
| **Exit ボタン** | ゲーム終了 |
| **キー操作** | ↑↓ / Tab でボタン切替、Enter / Space で決定 |
| **マウス操作** | ホバーで選択切替、クリックで決定 |

### ゲーム中 HUD

| 要素 | 表示条件 |
|------|---------|
| **砂時計ゲージ** | `A` キーを押している間のみ表示、満タンで非表示 |
| **キーインジケーター** | 常時表示（操作ガイド） |
| **リセットウィジェット** | `R` キー押下でフェードアニメーション表示 |

### ステージクリア画面

| 要素 | 内容 |
|------|------|
| **表示タイミング** | ボールが外枠を出た瞬間 |
| **Next Stage ボタン** | 次のステージへ遷移（最終ステージの場合はメインメニューへ） |
| **入力モード** | UI 専用（ゲームへの入力は無効化） |
